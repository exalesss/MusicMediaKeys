# Инструкция по использованию Music Media Keys

## Установка и первый запуск

1. **Установка или портативный запуск:**
   - Запустите `MusicMediaKeys-Setup.exe` — выберите один из **29 языков** в каталоге, папку установки и нужные параметры запуска. Для удаления используйте стандартный список приложений Windows («Установка и удаление программ»).
   - Либо используйте портативный `MusicMediaKeys.exe` напрямую (без установки).
   - Для сборки из исходников (требуется `.NET 10 SDK`): `build-installer.bat` (установщик + единый EXE) или `build-single-exe.bat` (только единый EXE в `bin\SingleExe\`). Для обычной Release-сборки — `dotnet build -c Release`.
2. **Права администратора и SmartScreen:**
   - Приложение запрашивает **права администратора** для надёжной работы глобальных хоткеев поверх окон и игр с повышенными правами без ограничений Windows UIPI. Весь исходный код открыт для аудита в репозитории ([LICENSE](LICENSE)).
   - При первом запуске неподписанного EXE Windows SmartScreen может показать предупреждение — нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
3. На первом старте откроется **мастер настройки**: выберите язык, тему, управляемый плеер и базовые горячие клавиши, затем нажмите **«Сохранить и завершить»**.
4. После запуска иконка приложения появится в системном трее (область уведомлений).

## Базовое управление

- **FN+F6** — предыдущий трек
- **FN+F7** — воспроизведение / пауза
- **FN+F8** — следующий трек
- **FN+F2 / FN+F3 / FN+F4** — громкость тише / выключить звук / громче

Все комбинации можно переназначить или полностью очистить на вкладке **«Горячие клавиши»**.

## Основные настройки

Открыть окно настроек можно **двойным кликом** по иконке в трее или через **правый клик → «Открыть»** (или сразу **«Горячие клавиши»**). Пункт смены плеера в меню трея позволяет переключаться между **«Авто»** и обнаруженными запущенными плеерами без закрытия меню (меню закроется, когда курсор уйдёт за его пределы).

1. **Управляемый плеер и режим работы:**
   - **Авто** — автоматически определяет запущенный Spotify или Яндекс Музыку.
   - **Spotify / Яндекс Музыка / Свой плеер** — привязка команд к конкретному плееру или указанному процессу.
   - **Управлять любым плеером** — отправка команд в текущий активный плеер (включая браузеры) через Windows Media Session (GSMTC) или активное окно; в этом режиме регулируется общая громкость системы.
   - **Блокировать медиаклавиши для браузера** — не отправляет команды в браузер, оставляя управление за музыкальным плеером.
2. **Всплывающий оверлей трека:**
   - Показывает карточку с обложкой (и размытым фоном для неквадратных обложек / YouTube Shorts), названием, исполнителем, интерактивным таймлайном трека (перемотка перетаскиванием или кликом) и ползунком громкости.
   - В кнопке **«Настроить»** доступны: выбор одной из 8 позиций на экране, длительность показа (`1`–`10 сек`), масштаб (`75%`–`140%`), скрытие поверх полноэкранных игр/приложений и кнопка тестового показа.
3. **Шаг громкости и шаг перемотки:**
   - Выберите готовый пресет шага громкости (`1%`–`100%`) или шага перемотки (`1`–`300 сек`) либо задайте собственное значение.
4. **Оформление, язык, звук и подсказки:**
   - Выбор **светлой** или **тёмной** темы и одного из **29 языков** интерфейса (ISO-меню в нижней панели).
   - **Воспроизводить звук при запуске** — встроенный звук или собственный аудиофайл; при выключении предпрослушивание прерывается мгновенно.
   - Кнопка **`(i)`** в интерфейсе отключает или включает всплывающие подсказки.
   - **Экспорт / Импорт** настроек в `.json` для переноса конфигурации или резервной копии.
5. **Запуск и система:**
   - **Автозапуск** — регистрация задачи входа в Планировщике заданий Windows (приложение должно находиться в постоянной папке, не в `Downloads` или `Temp`).
   - **Запуск без подтверждения UAC** — создаёт задачу Планировщика для запуска от имени администратора без повторного окна UAC.
   - **Проверять обновления** — автоматическая проверка новых версий на GitHub Releases с установкой из интерфейса и проверкой SHA-256.

## Горячие клавиши и дополнительные действия

- Кликните по полю нужной команды и нажмите комбинацию клавиш (`Esc` — отмена ввода).
- Правый клик по полю — выбор системной медиаклавиши или пункт **«Очистить»**.
- В блоке **«Действия приложения»** можно назначить отдельные хоткеи для перемотки трека назад/вперёд, копирования названия трека в буфер обмена, показа/переключения оверлея, смены плеера, переключения режима любого плеера и быстрого открытия окон программы.
- При совпадении комбинаций поля автоматически подсвечиваются красным.

## Важные замечания и устранение проблем

- В установленном режиме настройки хранятся в `%AppData%\MusicMediaKeys\settings.json` (с резервной копией `settings.json.bak`), логи — в `%AppData%\MusicMediaKeys\Logs\`. В портативном режиме поддерживается локальное хранение рядом с EXE.
- **Горячие клавиши не срабатывают:** проверьте, что комбинация не занята другой программой или игрой, и не подсвечена красным как дубликат.
- **Приложение не управляет браузером:** включите опцию **«Управлять любым плеером»** (и убедитесь, что отключена блокировка медиаклавиш для браузера, если она не нужна).
